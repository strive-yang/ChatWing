# 使用指南

返回[项目首页](../README.md)。安装方法见首页的「安装」部分。

## 打开与固定目录

进入一段 ChatGPT 对话，将鼠标移到页面右侧细栏，目录会自动展开。每个目录项对应一次提问，当前阅读位置对应的条目会高亮。

鼠标移开后目录会自动收起。需要连续浏览时，点击图钉固定目录；再次点击图钉取消固定。点击细栏也可以展开并固定目录。

按 **Esc** 或点击关闭按钮，会取消固定并收起目录。

## 预览与跳转

悬停目录项可预览完整提问和回答开头，较长提问可以在预览区域内滚动。预览只展示文字，不展示图片、附件或完整回答。

点击目录项会滚动到对应提问，并短暂高亮。跳转动画遵循系统的「减少动态效果」设置。未固定的目录会在跳转后收起。

新提问、回答生成和编辑提问时，目录会自动更新；在 ChatGPT 内切换聊天也会重新识别当前对话，无需每次刷新页面。

## 键盘操作

先按 **Tab** 将焦点移动到目录细栏或目录内的按钮。

| 按键 | 操作 |
| --- | --- |
| Tab / Shift + Tab | 在可交互元素之间移动焦点 |
| ↑ / ↓ | 在目录项之间切换 |
| Home / End | 跳到第一个或最后一个目录项 |
| Enter | 激活当前按钮或跳转到选中的提问 |
| Esc | 收起目录，并停止正在进行的补全 |

方向键和 Home / End 在目录项获得焦点时生效。

## 补全长对话

ChatGPT 可能只渲染当前阅读位置附近的内容。遇到目录不完整或显示「提问内容待加载」时，展开目录并点击圆形箭头。

补全过程会短暂滚动当前聊天，触发站点加载消息，结束后恢复原来的阅读位置。再次点击箭头或按 Esc 可以停止；主动滚动也会中止补全。补全期间点击目录项，会停止补全并保留你选中的跳转位置。

该功能依赖网页正常加载，无法保证读取到站点尚未提供的消息，也不会检索账号中的其他聊天。

## 常见问题

### 安装后没有出现目录

1. 在 `chrome://extensions` 确认 ChatWing 已启用，且加载目录中有 `manifest.json`。
2. 确认当前页面位于 `chatgpt.com` 或 `chat.openai.com`。
3. 刷新 ChatGPT 聊天页。首次安装和扩展更新后，都需要重新加载已经打开的页面。

### 有对话却显示「暂无消息」

先点击圆形箭头重新检测，并等待页面消息加载。如果仍无法识别，可以展开「查看识别状态」，在 GitHub Issue 中提供统计、扩展版本和复现步骤。

识别统计只包含版本、加载状态和节点数量，不包含聊天内容、会话 ID 或登录信息。提交反馈时请勿附上真实聊天、令牌或其他个人信息；优先提供可公开的最小示例。

ChatGPT 页面结构变化可能需要更新扩展。自动测试使用本地复现页面，不能保证覆盖每种真实账号布局。

### 更新后仍然是旧版

确认替换的是 Chrome 当前加载的那一个目录，然后依次执行：

1. 在 `chrome://extensions` 点击 ChatWing 卡片上的刷新按钮。
2. 刷新 ChatGPT 聊天页。

如果改用了新的解压目录，可以移除旧扩展，再加载新目录，避免同时保留两份 ChatWing。加载后的文件夹必须保留。

### 能否查看其他聊天或同步目录

当前只整理正在打开的聊天分支，不列出账号下的其他聊天，也不保存或跨设备同步目录。刷新页面后，会重新从当前页面读取消息。
